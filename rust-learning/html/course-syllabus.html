Course Syllabus

课程大纲与交付标准

链路站 架构 案例课 模块 验收

Audience

面向有 C++/系统背景、想进入 Rust 推理工程的人

这套资料不按语法书顺序讲 Rust，而是沿一次 Candle LLM 推理请求学习语言、Tensor 系统和工程边界。学员最终要能读懂真实 LLaMA forward，并能小范围修改 tour 代码且补测试。

Modules

7 个模块覆盖从入口到后端

0. 工程地图

workspace、crate、example、core、nn、transformers 的边界。

  • 能说明 Candle 分层
  • 能找到 LLaMA 入口和模型实现
  • 能跑 rust-candle-tour

0.5 项目架构全景

从 workspace 到 Tensor 内部结构，再到 Storage 后端分发和错误定位。

  • 能解释依赖方向
  • 能区分模型态、请求态、临时 Tensor 态
  • 能用定位表分析 shape/device/weight 错误

1. Rust 基础嵌入推理主线

用 `Args`、`parse_prompt`、`Result`、`Option`、borrow 学 Rust。

  • 能解释 `?` 和 `bail!`
  • 能修复 Vec slice 与 push 的借用冲突
  • 能写输入校验测试

2. Tensor 合同

shape、dtype、device、layout、stride、contiguous。

  • 能手算 `[B,S,H] -> [B,N,S,D]`
  • 能解释 view 和 copy
  • 能读 `--trace-shapes` 输出

3. 权重加载

VarBuilder 路径、SafeTensors、mmap、config 校验。

  • 能从 `vb.pp` 推导权重名
  • 能区分模型态和请求态
  • 能定位 shape/name mismatch

4. Attention 与 KV Cache

prefill、decode、causal mask、cache append、recompute 对比。

  • 能解释 `S` 和 `T` 的区别
  • 能说明 cache 为什么请求独立
  • 能验证 cached/recompute 一致

5. Sampling 与停止条件

greedy、temperature、top-k/top-p、RNG、EOS。

  • 能用 enum/match 表达状态空间
  • 能说明 EOS 检查位置
  • 能扩展多 EOS 并补测试

6. 工程化与 unsafe 边界

feature、cfg、tracing、并发状态、mmap/FFI safety invariant。

  • 能区分编译期 feature 和运行时参数
  • 能设计请求独立 cache 的服务状态
  • 能写 unsafe 审计条目

Learning Tracks

三种学习节奏

3 天速通

只跑 tour 命令、读 HTML 链路站、完成考题 A/B/D。适合已有 Rust 基础的人快速建立 Candle 主线。

7 天标准

每天一个模块，配合 labs 做小破坏和修复。最后完成 100 分考题和两道实操题。

14 天深读

前 7 天走 tour，后 7 天追真实 LLaMA、VarBuilder、Tensor/Layout、backend dispatch。

企业内训

用 HTML 链路站讲整体，trace 案例页做课堂拆解，考试和评分参考做课后验收。

Evidence

交付物和验收证据

交付物 验收证据
HTML 链路站 可离线打开，能交互切换阶段、shape 实验台和 checklist。
项目架构全景图 能说明 workspace、crate 边界、Tensor 合同、后端分发和 bug hunt 方法。
trace 案例课 能把 stdout 逐行映射到 shape/dtype/cache/EOS 不变量。
tour 示例代码 `cargo test -p candle-examples --example rust-candle-tour` 通过。
实验手册 每个实验有运行、观察、小破坏、修复、达标问题。
考试和评分参考 题目、分值、答案要点、扣分点和补课路径分离。
真实 bug 报告 至少包含一个可复现 bug、修复说明和测试命令。
