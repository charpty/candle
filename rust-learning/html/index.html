State Ownership

三类状态不要混在一起

模型态

权重、配置、只读模块。可以跨请求共享，但加载失败属于启动期错误。

  • Embedding / Linear / Attention 权重
  • VarBuilder 路径和 dtype/device
  • TinyConfig 与真实 LLaMA config

请求态

tokens、KV Cache、sampler、EOS。每个请求独立，否则会发生上下文串扰。

  • prompt token ids 与已生成 token
  • K/V cache 长度和 index_pos
  • RNG seed、temperature、top-k/top-p

临时 Tensor 态

forward 内部的 shape、dtype、layout、device。错误大多通过 Result 返回。

  • input [B,S]、hidden [B,S,H]
  • Q/K/V [B,N,S,D] 与 scores [B,N,S,T]
  • stride、start offset、contiguous
